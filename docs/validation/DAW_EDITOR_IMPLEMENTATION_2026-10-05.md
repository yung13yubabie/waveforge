# 多軌歌曲編輯器：實作範圍與驗收

日期：2026-10-05。這份文件描述本次程式碼；是否已上線，以對應 PR、精確 commit 的 CI 及正式部署結果為準。完整專業 DAW 規劃仍見 `docs/planning/`，不能把規格表當成已實作功能。

## 使用方式

1. 打開「歌曲編輯」，加入有權使用的音檔。每份音檔先成為一軌；原檔不會被剪壞
2. 選片段後，可拖動或輸入秒數移動、在播放游標切開、裁掉兩端、複製或刪除，再用復原找回
3. 調每軌音量、左右位置、靜音或獨聽；淡入／淡出讓片段接頭不突然。BPM 只控制格線，不會把音檔變快或變慢
4. 預聽會先合成目前版本。輸出 WAV 使用同一份合成結果；超過可輸出音量時會要求降低總音量，不偷偷壓縮
5. 離開前下載「儲存工程 ZIP」。它包含原始音訊和多軌編排／混音設定。下次用「開啟工程」還原，不必再找原檔
6. 「送往母帶」把目前混音交給原有母帶工作區。母帶設定及獨立歌詞草稿不包含在這份多軌 ZIP；歌詞須在歌詞區另外保存

## 按鈕到聲音、保存及測試

|操作|資料與處理|保存／復原|驗收路徑|
|---|---|---|---|
|加入、移動、裁切、切開、複製、刪除|`daw/project.js` 命令改 source offset／timeline time，不改原 PCM|ProjectHistory；ZIP manifest|daw-project、daw-panel、daw-editor|
|每軌音量、左右、靜音、獨聽、總音量|`daw/render.js` 共用 OfflineAudioContext 圖|命令歷史及 manifest|daw-render 單元及真實瀏覽器 render|
|淡入／淡出|裁切及切開後保留相同增益包絡|片段資料及歷史|split／trim sample parity 回歸|
|預聽、跳轉、停止、WAV|同一 revision 的合成 buffer；16／24-bit WAV|音檔下載；參數存在工程|daw-editor 實際下載與 PCM／取樣率檢查|
|儲存／開啟 ZIP|`archive.js` 儲存原始 bytes；CRC、SHA-256、路徑與大小驗證後才替換|完整多軌原音／編輯；非自動保存|archive 單元、Python ZIP 交叉讀取、全新還原／播放／匯出瀏覽器流程|
|取消、切頁、再次匯入、送往母帶|shared decode gate、AbortSignal、revision guard，丟棄晚到結果|取消不覆蓋原專案或母帶來源|daw-decode、daw-panel、daw-transfer|

入口為 `main.js` → `daw/panel.js`，畫面在 `index.html`／`daw.css`。只隱藏不適用的母帶全域控制，不留下只改畫面的假按鈕。

## 留存、大小與已知限制

- 多軌音訊、渲染快取及操作歷史在目前分頁記憶體。沒有背景上傳或伺服器工程。關頁／瀏覽器崩潰會失去尚未下載的多軌工程
- ZIP 會保留原始音訊於使用者下載位置；網站不能替使用者刪掉本機下載。另有歌詞備份、模型快取及帳號作品資料，須使用各自功能管理
- 上限：10 分鐘 timeline、16 軌、256 片段、64 素材；單一原檔 64 MiB；archive／decoded／render 各有 256 MiB 級別限制，混合保守預算 512 MiB。這不是瀏覽器總記憶體保證，較弱裝置可能更早不足
- 解碼超時／取消後，原生 decode 還未結束時不能無限堆下一次工作；會明示稍候再試。原生離線渲染也不能保證立即停止底層計算
- 預聽是離線合成後播放，不是完整低延遲錄音 DAW。大檔同步峰值掃描仍可能造成短暫卡頓
- 尚無 MIDI、錄音／監聽、節拍伸縮、音高校正、音符編輯、複雜路由、插件宿主、即時自動化曲線編輯、AI 換聲或改詞重唱
- ZIP 只接受本版本支援的 stored ZIP；不接受加密、壓縮 entry、ZIP64 或任意外部工程格式

## 驗證狀態

本地整合：915 項單元通過，1 項需要人工金標的模型品質測試 skipped；154 個 JavaScript 語法檢查、136 項能力規格結構檢查、4 項 Python 測試與 production build 通過。模型實際 CPU 記錄見 `real-model/`。

本地 Chromium 在啟動時被執行環境 socket 權限阻擋，不能把測試發現／列出算成執行通過。PR 工作流會跑真正瀏覽器的多軌 UI、預聽／匯出、ZIP 還原、取消轉送及固定模型驗證。合併前須檢查該精確提交的 CI 與畫面證據。

獨立審查先重現並修正：重複取消堆積解碼、延遲 AudioContext resume 隱藏播放、取消／清空後舊轉送覆蓋母帶、編輯未失效轉送、restore 無 deadline、記憶體預算漏算、鍵盤焦點選取不同步。修正後相同 probes 及相鄰回歸通過；瀏覽器層仍由上述 CI 提供證據。
