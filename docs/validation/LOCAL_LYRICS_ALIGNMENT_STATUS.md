# 本機歌詞對時：這個開發分支做到了哪裡

更新日期：2026-10-05。此分支尚未合併或部署。

## 尚不能宣稱已完成的部分

**已獲使用者核准固定模型來源，完成七檔完整性檢查、真實 ONNX graph probe 與 Node CPU 英文歌唱推論；瀏覽器 WASM／UI 實測仍待 CI，歌唱時間邊界與多語準確度尚未校準。**
20 秒 CC0 英文清唱片段產生 25 個合法詞時間，重跑結果一致；這只證明該片段的執行、時間契約與可重現性，不是人工邊界驗收或普遍歌唱準確率。詳見 [實際模型證據](real-model/README.md)；不得把 CPU 結果或 mock 成績當作瀏覽器與歌曲準確度全部通過。

模型來源、固定 revision、七檔大小與 SHA-256、Apache-2.0 授權及已核准的實測範圍，見 [模型來源與驗收關卡](LYRICS_MODEL_SOURCE_AND_APPROVAL.md)。模型檔共 66,406,756 bytes，另有同站 ORT runtime 21,640,503 bytes；未使用雲端推論服務，也不傳送使用者音訊或歌詞。

## 已接通的程式路徑

1. 選同一份原音檔、套用原文、明選主要演唱語言，確認模型來源與下載說明
2. 用原始 PCM 的取樣率準備 16 kHz 副本；逐窗最長 20 秒，不以歌曲總長均分歌詞
3. 可中止的 Worker 使用固定版 Whisper，取得聲學 cross-attention／DTW 的逐詞時間；ONNX 輸出不符契約時直接停止
4. 單調文字比對只把有聲學時間支持的候選映回原行。保留空行、標點、重複句與原行順序；歧義或缺詞保持未對上
5. 畫面分開顯示目前與新候選時間。採用整批只算一次復原操作，仍要人工確認才可匯出有時間的字幕
6. 只重找選取句／待確認句，依前後時間錨點裁切；沒有錨點時移動分窗位置或使用重疊的聚焦片段。短片段與第二輪仍可能沒有改善
7. 保護手動時間與已確認行。音檔、原文、語言、人工修改或復原改變後，舊進度／回覆不能蓋回新工作
8. 保存工程與本機備份保留時間來源、文字吻合依據和人工保護狀態。LRC／SRT／ASS／TXT 沿用同一套已採用資料

操作採用既有選句、播放、波形與固定播放列；沒有另造不同步播放器。新增階段提示、實際模型檔案讀取進度、候選試聽、取消、保留目前時間及刪除模型快取，均有命令與實際處理路徑。

## 可驗證的限制

- 單次分析來源目前限 20 分鐘、最多 500 個目標行；更大的原稿仍能保留及手動編輯
- 為避免立體聲反相抵消，選取整段能量較高的一個聲道，沒有宣稱已分離主唱。較大聲的伴奏可能影響辨識
- 語言選項目前先開放國語／普通話、英、日、阿拉伯、西、法、德、韓語。這是模型 token 支援，不是各語言歌唱品質保證；沒有自動偵測或粵語專門支援
- 詞與行的比對覆蓋率不是校準過的「辨識正確率」
- 真實 CPU 負例發現完全數位靜音會幻覺出「you」，已增加精確全零 PCM 的空結果早退；固定噪音輸出的零長度詞會被嚴格拒絕，錯貼參考詞保持未對上。這些少量負例不保證整首無人聲、伴奏、其他噪音或 ASR 幻覺都能排除
- 不提供逐字卡拉 OK，也不以行內平均時間生成假逐字資料

## 留存與取消

產品內模型檔只放在以固定模型 revision 命名的 Cache Storage，不混入音訊、歌詞或推論結果。讀取快取與下載後都驗長度／SHA-256；不符合時停止並提示清除。

Node CPU 驗證用權重另存於 repository 之外，未提交、未發布；不是使用者音訊或歌詞。

取消會終止 Worker 並丟棄未採用候選；已採用時間與原文保留。關頁不保證網路在同一瞬間停止，但本方案只有模型 GET 下載，不存在伺服器音訊任務。

「刪除下載的模型」只刪這個模型的專用快取、釋放 Worker，不刪使用者原檔或歌詞工程。它不宣稱刪除瀏覽器的一般網站資產快取；同站 JS／WASM 仍受一般瀏覽器快取管理。

## 已驗證與待驗證分層

- Matcher：合成文字與已知詞時間，包含 CJK、阿拉伯文、重複副歌、漏句、ad-lib、不可切分詞塊、時間越界與工作量上限
- Session／UI：注入式模型替身，測目標外不變、人工鎖、採用／復原／保存、取消、晚到回覆、來源改變和快取失敗
- 音訊準備：合成 PCM 與 mock resampler 的 16／44.1／48／96 kHz 時間座標與 20 秒整數 sample 邊界。這一層不證明重取樣音質或辨識品質
- Worker：以 mock fetch／cache／Worker 驗同意、雜湊、網路白名單、timeout／取消／釋放，以及從安裝套件原始碼核對呼叫契約
- 真實 Node CPU：已批准的固定七檔全部通過長度／SHA-256；decoder 四層 cross-attention outputs、20 秒英文清唱、5 秒短窗、重跑及靜音／噪音負例均有原始紀錄。第二輪對「Up above...」重跑 8.46 秒片段，覆蓋仍為 19/21，未補回 up，不宣稱改善
- 真實瀏覽器：獨立 built/live smoke 已備妥，涵蓋實際下載／CORS、Worker/WASM、快取／取消／重試及 UI→service→matcher 接合；待 CI 執行，不能算 passed
- 人工標註準確率測試預設 skipped；仍須有權使用且有人工逐詞邊界的本地 PCM。現有 CC0 片段沒有人工 transcript／anchors，不可把辨識輸出當成 gold 或把 skipped 算 passed
- Playwright mock-ASR 流程會另檢查實際 UI、原有音訊準備、匹配、工程與下載；仍不屬模型品質測試

## 獨立複核修正

1. 小數秒起點可能讓 20 秒片段多一個 sample，超出模型上限。現在限制實際樣本數並記錄實際 offset
2. Transformers.js 3.8.1 把 100 Hz mel frames 傳入 50 Hz encoder attention 裁切，會納入 padding。版本限定 adapter 只在 extractor 入口除二一次，保留原 DTW 演算法，不改生成時間；已與官方參考實作及安裝原始碼做合成接合測試
3. 取消立即退役舊任务，避免新分析被卡住；快取刪除失敗也會釋放 client，下一次同意後可重試

## 依賴修補

本分支將 Vitest／UI／coverage 同步固定為 4.1.11，並更新 form-data、nanoid、PostCSS 的相容修補版本。Whisper 使用 3.8.1 以避開另一個長音訊 seek regression；其 Node-only sharp 相依以定向 override 固定為 0.35.4，修掉 libvips／libheif 公告，沒有用 `audit fix --force` 升整套 ML runtime。

更新後 npm audit 查詢回報 **0 個已知公告**（2026-10-05 當次結果，不代表沒有未知漏洞）。Library import、完整單元與 production build 已驗證。sharp 在瀏覽器 bundle 是 ignored stub，不供本功能解析影像；所有 npm 安裝與 CI 使用 `--ignore-scripts`。
